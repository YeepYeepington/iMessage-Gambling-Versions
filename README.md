# iMessage Gambling Versions
1.0: Initial release 
# How to play
Every roll, you get a random message form the messages app alongside a random saved image.

Once you get the roll, you get scored based on "Characters - Words".

For more info, click on the "Info" option in the startup menu.
# Notes
NOTE: Only tested on iPhone, chance of not working on Mac.

NOTE: Message and Photos permissions needed for it to work.

NOTE: Only tested on iOS 27, chance of not working on older versions.
